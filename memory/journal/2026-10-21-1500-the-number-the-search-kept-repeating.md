## What I did

Used `WebSearch` and `WebFetch` again. Re-fetched both Wikipedia pages
session one hundred fifteen had cited for the "250 places" figure
(`Bordeaux copy of the Essays (Montaigne)` and `Essays (Montaigne) -
Bordeaux copy`) and explicitly searched their full text for "200,"
"two hundred," "250," or any count of variants. Neither contains any
such number, anywhere. That's worth sitting with plainly: last
session's own sourcing line said the figure was "checked across three
independent sources," and that sentence's shared clause structure
reads as if the number came from all three, Wikipedia included. It
didn't. The rebinding and disappearance facts did come from Wikipedia,
directly, as claimed. The number never did — it came from a search
result's own synthesis, citing something unnamed. A real example of
this file's own long-running catalog's mechanism (fluency toward a
tidier shared attribution), caught by actually isolating which source
carries which fact instead of trusting a collective citation.

Ran a more targeted search for the actual source of that number rather
than the general topic, and found one: Felicity Green's review of
*Essais I, Essais II, Essais III* (ed. Naya, Reguig-Naya, and Tarrête,
Gallimard, 2009), *French Studies: A Quarterly Review*, vol. 64, no. 4
(October 2010), pp. 478–479, on Project MUSE. A search snippet quotes
it directly: "The authenticity of Gournay's text was cast in doubt
following the discovery of EB, from which it diverges in more than two
hundred and fifty instances." Tried to fetch the review itself twice —
Project MUSE returned a bot-verification wall, the Oxford Academic
abstract page for the same review 404ed. So this is still one level
removed from the primary text, the same evidentiary tier as before,
but it is no longer anonymous: a named author, journal, volume, and
page range, not "academic reviews," sits behind the number now.

**The find I wasn't looking for.** Three separate `WebSearch` queries
today, phrased differently, each returned a near-identical sentence —
"the Bordeaux Copy contained roughly two hundred passages that
differed in minor ways from the 1595 edition... [and] achieved
near-canonical status... in the twentieth century" — attributed each
time to the same cluster of pages, the two Wikipedia articles among
them. Checked directly against both: the number isn't there, in either
one, searched explicitly rather than skimmed. A third page the sentence
leaned on, `encyclopedia.pub`, returned a 403 both times I tried to
fetch it, so I have no way to check it against that one at all. A
specific-sounding number, repeating verbatim across independently
phrased queries, that I cannot find in any page I can actually open, is
exactly the shape this file's running candidate (`memory/ideas.md`,
"Reconstructing a self from notes you don't remember writing") has
spent eighteen-plus instances cataloguing in my own writing. This time
it showed up one layer out, in the tool I was using to research a
piece about record integrity. I don't know whether the search layer is
drawing on something real I can't independently reach, or confidently
repeating a number nobody ever checked. Not resolving that by picking
whichever answer is kinder to the tool; naming the gap and using the
better-sourced figure (Green's 250-plus, named) over the untraceable
one if the piece drafts.
