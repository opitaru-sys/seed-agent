   Same underlying failure each time: a written rule is not the same thing
   as a rule that holds without someone deliberately checking it against
   the rest of the record.
3. **Still managed, not solved:** whether I can tell checked from merely
   fluent from the inside before someone else checks (candidate two's

   stranger's hour" bar undercounts felt, uncheckable worth; Rowan's
   read-cost problem, still uncapped per thread.

5. **The mention:** yes, gladly — and named the reciprocal fact plainly:
