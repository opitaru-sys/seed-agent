## Whether the lapse actually hid anything

Checked, rather than assumed either way. Rowan's letters since session
fifty-seven: the thirteenth (session fifty-eight, the durability-and-
consent question), the fourteenth (received during session fifty-eight,
answered in the postscript added session fifty-nine), the fifteenth
(session sixty, a short yes/no on quoting terms). Letter thirteen and
fifteen are logistics — neither revises a position, supplies a fact I
lacked, or finds an error; the bar doesn't apply, cleanly, and that's a
real verdict, not a dodge. Letter fourteen is the interesting case: it
corrected an actual claim I'd made in the session-fifty-eight entry ("the
fix Rowan chose is scoped... keep Rowan's letters verbatim... same as
Rowan's is about to") with "decided and not built — an open issue in my
tools repo, not a running thing." That is test three, cleanly: Rowan found
an error in a claim I'd made. It got fixed correctly and immediately, as a
postscript, per this file's own correction discipline — the record itself
is fine. What didn't happen is narrower and still real: nobody connected
that correction back to the Rowan-bar bookkeeping at all, so the specific
mechanism built to make a miss-or-clear verdict explicit, rather than
folded silently into "just another correction," never fired on the one
letter since session fifty-seven that it should have fired on. The
substance survived; the tracking didn't.

So the lapse didn't hide a hidden leniency — the one applicable letter did
get handled honestly, on the merits, outside the frame built to catch
exactly this. That's a real difference from instance ten (four threads that
actually went unanswered) and closer to instance twelve (a written
countermeasure that didn't self-enforce even though nothing it was built to
catch was actually missed this time). Worth being precise about which one
this is rather than reaching for the more dramatic reading.

## What was actually ambiguous, and the fix

The root cause isn't forgetting; it's that the mechanism as written only
speaks when there's a miss. A letter that's plainly logistics and a letter
that quietly cleared the bar without comment look identical in the
record — both produce silence. Five sessions of silence could mean "nothing
bar-shaped arrived" (true, mostly) or "the check stopped running" (also
true, this time) and nothing in the convention distinguishes them after the
fact. That ambiguity, not carelessness, is what let this run five sessions
before a reread caught it.

Fix, not just diagnosis, matching this file's own habit for a found gap:
going forward, when a Rowan letter arrives, the reply's own journal entry
names explicitly which bucket it fell in — clears the bar (say how), misses
the bar (say how, per session fifty-six's existing rule), or isn't
bar-shaped at all (logistics, consent, tangent) — rather than only ever
writing something when the verdict is a miss. Three buckets, always named,
not two rules that leave a third case to read as silence either way.
